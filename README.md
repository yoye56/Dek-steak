# Dek Steak

ระบบสั่งอาหารและจัดการร้าน พัฒนาด้วย Python และ Streamlit เก็บข้อมูลด้วย SQLite ใช้ HTML/CSS และ JavaScript ในส่วนแสดงผลบางส่วน

## ความสามารถ
- สมัครสมาชิกและเข้าสู่ระบบด้วยอีเมล @gmail.com
- เลือกอาหาร ทานที่ร้านหรือสั่งกลับบ้าน จัดการตะกร้าและออเดอร์
- แจ้งชำระเงินและแนบหลักฐาน โดยเจ้าของร้านตรวจสอบการรับเงินจริง
- จัดการเมนู โต๊ะ คิวอาหาร และรายงานยอดขาย
- ใบเสร็จสำหรับพิมพ์และดาวน์โหลด PNG
- ภาษาไทย อังกฤษ จีน และธีมสว่าง/มืด
- รีเซ็ตรหัสผ่านทางอีเมล OTP เมื่อผู้ติดตั้งตั้งค่า SMTP แล้ว

ราคาเมนูรวม VAT 7% แล้ว เช่น ราคา 100 บาท จ่าย 100 บาท แยกเป็นราคาก่อน VAT 93.46 บาท และ VAT 6.54 บาท

## วิธีเปิดใช้งาน
ติดตั้ง Python 3.11 ขึ้นไป ดาวน์โหลดและแตกไฟล์โปรเจกต์ จากนั้นเปิด Terminal ในโฟลเดอร์นี้แล้วรัน:

```sh
python start.py
```

ตัวเริ่มโปรแกรมจะเตรียมสภาพแวดล้อม ติดตั้งไลบรารี และให้สร้างบัญชีเจ้าของร้านเมื่อยังไม่มีบัญชี จากนั้นเปิดเว็บตามที่อยู่ที่แสดงใน Terminal

หากติดตั้งด้วยตนเองบน Windows:

```sh
python -m venv .venv
.venv\Scripts\python.exe -m pip install -r requirements.txt
.venv\Scripts\python.exe manage.py setup-owner
.venv\Scripts\python.exe -m streamlit run app.py
```

## ส่วนประกอบสำคัญ
| ไฟล์ | หน้าที่ |
|---|---|
| app.py | หน้าจอและขั้นตอนใช้งาน |
| core.py | ข้อมูล กฎการสั่งอาหาร การชำระเงิน และรายงาน |
| brand_ui.py | รูปแบบหน้าจอและองค์ประกอบร้าน |
| i18n.py | ข้อความหลายภาษา |
| password_reset.py | ส่งอีเมลและตรวจสอบ OTP |
| receipt_design.py / receipt_png.py | ใบเสร็จ HTML และ PNG |
| theme_clock.py | ธีมตามเวลา |
| manage.py | สร้างบัญชีเจ้าของร้านในเครื่อง |
| configure_email.py | ตั้งค่าอีเมลผู้ส่งในเครื่อง |
| .streamlit/assets/ | รูปภาพประกอบ |

## ข้อมูลและการตั้งค่า
ระบบสร้างฐานข้อมูลใหม่ที่ `data/dek_steak.sqlite3` เมื่อเริ่มใช้งาน ชุดนี้ไม่รวมฐานข้อมูลลูกค้า สลิปจริง หรือรหัสผ่านส่งอีเมล

ตั้งค่าข้อมูลรับเงินและ QR ของผู้ใช้งานเองผ่านหน้าตั้งค่าร้าน ส่วนการส่ง OTP ให้รัน `python configure_email.py` แล้วกรอก Gmail ผู้ส่งและ Google App Password ในเครื่อง ข้อมูลลับบันทึกใน `.streamlit/secrets.toml` ห้ามอัปโหลดไฟล์นี้

GitHub นี้เป็นที่เก็บซอร์สโค้ด ไม่ใช่เว็บที่เปิดให้ลูกค้าใช้งานออนไลน์ การเปิดผ่านอินเทอร์เน็ตต้องติดตั้งบนโฮสต์เพิ่มเติม
